
# Ahlem Ben Abdallah — Beyond the Code

A React + Vite personal portfolio with a cinematic purple visual identity, scroll-reveal storytelling, responsive navigation, project detail modals and a small easter egg.

## Run locally

```bash
npm install
npm run dev
```

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `src/App.jsx` with your professional email.
2. Replace the GitHub and LinkedIn profile URLs with your real profiles.
3. Add a real CV PDF to `public/cv/` and link it from the hero or navigation.
4. Add project screenshots, repository/demo links and verified project details in `src/data/portfolio.js`.
5. Review project statuses and descriptions so they accurately reflect what is completed or still in development.

## Structure

- `src/App.jsx` — page sections and interactions
- `src/index.css` — visual system and responsive styles
- `src/data/portfolio.js` — editable projects, skills and timeline

No backend is required for this first version.
